# AI Powered Face Recognition Attendance System

## Features

- Student Management
- Face Dataset Collection
- Face Recognition
- Attendance Management
- Dashboard Analytics
- CSV Export
- Excel Export
- Plotly Charts
- SQLite Database
- Streamlit Dashboard

## Technology

- Python
- Streamlit
- OpenCV
- SQLite
- Pandas
- Plotly

## Run Project

```bash
pip install -r requirements.txt

streamlit run streamlit_app.py
```
